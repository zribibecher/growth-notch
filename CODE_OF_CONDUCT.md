# Code of Conduct

Be kind and be useful. This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behavior

- Be respectful, patient and constructive, especially with first-time contributors.
- Criticize code and ideas, not people.
- Assume good intent, and ask before assuming otherwise.

## Unacceptable behavior

- Harassment, insults, discriminatory language, or personal attacks.
- Publishing others' private information.
- Spam, self-promotion unrelated to the project, or bad-faith issue and pull request traffic.

## Enforcement

Maintainers may edit, hide or remove comments, issues and pull requests, and may block people who violate
this code. To report a problem, contact the maintainer through
[GitHub](https://github.com/zribibecher) (private message or a private security advisory).
